Onderzoek HTML & CSS

Waarom noem je de eerste HTML-pagina meestal index.html?

Index.html is meestal de eerste pagina van een website. Een webserver zoekt dit bestand vaak automatisch als je alleen de website opent.

Welke HTML-standaard gebruiken webontwikkelaars tegenwoordig en waarom wordt deze een "Living Standard" genoemd?

Tegenwoordig gebruiken webontwikkelaars de HTML Living Standard. Deze heet zo omdat HTML steeds wordt bijgewerkt. Er komt dus niet steeds een nieuwe grote versie.

Waarom spreken webontwikkelaars tegenwoordig meestal niet meer over één specifieke CSS-versie?

CSS bestaat uit verschillende onderdelen. Deze onderdelen worden los van elkaar aangepast. Daarom is er niet één nieuwe CSS-versie.

Waarom ziet een website er soms net iets anders uit in verschillende browsers, zoals Chrome, Firefox of Safari?

Browsers werken niet altijd precies hetzelfde. Ze gebruiken verschillende technieken om websites te laten zien. Daarom kan een website er soms iets anders uitzien.

Welke drie webbrowsers worden momenteel wereldwijd het meest gebruikt?

Volgens StatCounter waren in augustus 2026 de drie meest gebruikte browsers wereldwijd: Chrome, Safari en Edge. De bron is StatCounter. De statistieken zijn gecontroleerd op 30 september 2026.
